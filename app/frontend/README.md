# English Center — Frontend

Website trung tâm tiếng Anh: trang chủ công khai + dashboard theo vai trò (student / teacher / admin).

## Chạy
```bash
npm install     # lần đầu
npm run dev     # http://localhost:5173
```
Trước khi push: `npm run lint && npm run typecheck` phải xanh.

## Đăng nhập thử
Mật khẩu chung `123456`: `student@demo.com` · `teacher@demo.com` · `admin@demo.com`
(hiện đăng nhập bằng mock; nối backend ở plan `03`).
